# Карта проекта: Веб-квест на базе Marzipano

## 1. Общая концепция и архитектура
* **Движок 3D-тура:** Marzipano (экспорт из 3ds Max + Chaos Vantage).
* **Главное правило безопасности:** Исходные файлы 3D-тура (`index.html`, `index.js`, `data.js`, `style.css`, `tiles/`, `vendor/`) **НЕ ИЗМЕНЯЮТСЯ** без явной необходимости (в `index.html` подключены только 3 строки квеста перед `</body>`).
* **Изоляция квеста и редактора:** Весь код игры, графика, база данных, визуальный редактор и сервер разработки изолированы внутри папки `quest/`.
* **Разделение режимов (Игра / Редактор):**
  * **Игровой режим (`index.html`):** Подключает только `quest/quest.css`, `quest/quest_data.js` и `quest/quest.js`. Панель и кнопки редактора полностью отсутствуют.
  * **Режим редактора (`quest/quest_editor.html`):** Отдельная страница в папке `quest/`, использующая `<base href="../">` для загрузки 3D-тура из корня и дополнительно подключающая `quest/quest_editor.js`.

## 2. Структура файлов в папке `quest/`
* **`quest/quest.css`** — стили игрового HUD (панель инвентаря на 5 слотов внизу, всплывающие уведомления `#quest-toast`), прозрачные кликабельные контейнеры `.quest-hotspot` с PNG-иконками (размеры настраиваются в `:root` через `--q-item-size-pc`, `--q-lock-size-pc`, `--q-item-size-mob`, `--q-lock-size-mob`), анимация растворения замка `.dissolving` и стили панели редактора.
* **`quest/quest.js`** — чистый игровой движок (`gameState`, инвентарь на 5 слотов, подбор предметов, открытие замков, чтение записок) и публичный API (`window.QuestAPI`) для связи с редактором.
* **`quest/quest_editor.js`** — изолированный модуль визуального редактора уровней (`#q-editor-panel`), срабатывающий только на странице редактора. Позволяет снимать координаты по клику на `#pano`, создавать, редактировать (`✏️`) и удалять (`🗑`) объекты.
* **`quest/quest_editor.html`** — отдельная HTML-точка входа для режима разработки, открывающая 3D-тур сразу с панелью редактора.
* **`quest/quest_data.js`** — база данных игры (`window.QUEST_DATA = { items: [...] }`).
* **`quest/quest_server.js`** — локальный Node.js сервер разработки (порт `3000`, запуск: `node quest/quest_server.js`). Раздает игру по `http://localhost:3000/`, редактор по `http://localhost:3000/editor` (и `/quest/quest_editor.html`), а также обрабатывает POST-запросы `/save-quest-item`, `/update-quest-item`, `/delete-quest-item` для записи в `quest/quest_data.js`.
* **`quest/img/`** — папка с PNG-графикой игры (`key.png`, `lock.png`, `note.png`).
* **Деплой на продакшн:** При загрузке на боевой сервер из папки `quest/` исключаются файлы разработки (`quest_editor.html`, `quest_editor.js`, `quest_server.js`).

## 3. Структура объекта в `quest/quest_data.js`
Каждый объект в массиве `window.QUEST_DATA.items` имеет формат:
```json
{
  "uid": "q_1794796331890",
  "sceneId": "4",
  "type": "item | lock | note",
  "title": "Название объекта",
  "icon": "quest/img/key.png",
  "yaw": -2.2082,
  "pitch": 0.4606,
  "itemId": "key_bath",
  "requireItem": "key_bath",
  "message": "Текст при подборе / закрытом замке / осмотре записки",
  "successMessage": "Текст при успешном открытии замка"
}
```

## 4. Что уже реализовано и работает
1. **Разделение игры и редактора:** Редактор полностью вынесен в `quest/quest_editor.html` + `quest/quest_editor.js` и не загружается в основном `index.html`.
2. **Инвентарь (HUD):** 5 слотов внизу экрана, выбор активного предмета кликом (подсветка золотой рамкой).
3. **Подбор предметов (`type: "item"`):** Исчезает с панорамы, попадает в инвентарь.
4. **Замки (`type: "lock"`):** Крупнее стрелок перехода Marzipano (`z-index: 55`), блокируют клик по стрелке под собой. При применении нужного `requireItem` замок плавно растворяется (`.dissolving`) и удаляется, открывая проход.
5. **Визуальный редактор:** Определяет текущую сцену через `window.viewer.listScenes()`, снимает `yaw`/`pitch` по клику на `#pano`, позволяет создавать, полностью редактировать (`✏️`) и удалять (`🗑`) объекты с мгновенным сохранением в `quest_data.js`.

## 5. План следующих шагов (Бэклог)
* Очистка интерфейса 3D-тура (`index.html`, `style.css`, `index.js`) от лишних элементов застройщика/студии под формат игры.
* Модальное окно по центру экрана для чтения записок (`type: "note"`) и осмотра предметов крупным планом (с возможностью прикреплять картинку записки).
* Новый тип объекта — **Кодовый замок** (`type: "codelock"`) с интерактивной панелью ввода цифр `0–9`.
* Сохранение прогресса игрока в `localStorage` (с кнопкой «Начать игру заново»).
