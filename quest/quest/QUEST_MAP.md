\# Карта проекта: Веб-квест на базе Marzipano



\## 1. Общая концепция и архитектура

\* \*\*Движок 3D-тура:\*\* Marzipano (экспорт из 3ds Max + Chaos Vantage).

\* \*\*Главное правило безопасности:\*\* Исходные файлы 3D-тура (`index.html`, `index.js`, `data.js`, `style.css`, `tiles/`, `vendor/`) \*\*НЕ ИЗМЕНЯЮТСЯ\*\*.

\* \*\*Изоляция квеста:\*\* Весь код, графика, база данных и сервер разработки изолированы в папке `quest/`.

\* \*\*Подключение в `index.html`:\*\* Перед `</body>` подключены только 3 строки:

&#x20; ```html

&#x20; <link rel="stylesheet" href="quest/quest.css">

&#x20; <script src="quest/quest\_data.js"></script>

&#x20; <script src="quest/quest.js"></script>

&#x20; ```



\## 2. Структура файлов в папке `quest/`

\* \*\*`quest/quest.css`\*\* — стили игрового HUD (панель инвентаря внизу, всплывающие уведомления `#quest-toast`), прозрачные кликабельные контейнеры `.quest-hotspot` с PNG-иконками (размеры настраиваются в `:root` через `--q-item-size-pc`, `--q-lock-size-pc`, `--q-item-size-mob`, `--q-lock-size-mob`), анимация растворения замка `.dissolving` и стили визуального редактора.

\* \*\*`quest/quest.js`\*\* — движок игры (`gameState`, инвентарь на 5 слотов, логика подбора предметов, открытия замков, чтения записок) + встроенный визуальный редактор уровней (`#q-editor-panel`) с прицелом по панораме, созданием, полным редактированием (`✏️`) и удалением (`🗑`) объектов.

\* \*\*`quest/quest\_data.js`\*\* — база данных игры (`window.QUEST\_DATA = { items: \[...] }`).

\* \*\*`quest/quest\_server.js`\*\* — локальный Node.js сервер разработки (порт `3000`, запуск: `node quest/quest\_server.js`), который раздает сайт и обрабатывает POST-запросы `/save-quest-item`, `/update-quest-item`, `/delete-quest-item` для записи в `quest/quest\_data.js`.

\* \*\*`quest/img/`\*\* — папка с PNG-графикой игры (`key.png`, `lock.png`, `note.png`).



\## 3. Структура объекта в `quest/quest\_data.js`

Каждый объект в массиве `window.QUEST\_DATA.items` имеет формат:

```json

{

&#x20; "uid": "q\_1794796331890",

&#x20; "sceneId": "4",

&#x20; "type": "item | lock | note",

&#x20; "title": "Название объекта",

&#x20; "icon": "quest/img/key.png",

&#x20; "yaw": -2.2082,

&#x20; "pitch": 0.4606,

&#x20; "itemId": "key\_bath",

&#x20; "requireItem": "key\_bath",

&#x20; "message": "Текст при подборе / закрытом замке / осмотре записки",

&#x20; "successMessage": "Текст при успешном открытии замка"

}

```



\## 4. Что уже реализовано и работает

1\. \*\*Инвентарь (HUD):\*\* 5 слотов внизу экрана, выбор активного предмета кликом (подсветка золотой рамкой).

2\. \*\*Подбор предметов (`type: "item"`):\*\* Исчезает с панорамы, попадает в инвентарь.

3\. \*\*Замки (`type: "lock"`):\*\* Крупнее стрелок перехода Marzipano (`z-index: 55`), блокируют клик по стрелке под собой. При применении нужного `requireItem` замок плавно растворяется (`.dissolving`) и удаляется, открывая проход.

4\. \*\*Визуальный редактор:\*\* Определяет текущую сцену через `window.viewer.listScenes()`, снимает `yaw`/`pitch` по клику на `#pano`, позволяет создавать, полностью редактировать (`✏️`) и удалять (`🗑`) объекты с мгновенным сохранением в `quest\_data.js`.



\## 5. План следующих шагов (Бэклог)

\* Модальное окно по центру экрана для чтения записок (`type: "note"`) и осмотра предметов крупным планом (с возможностью прикреплять картинку записки).

\* Новый тип объекта — \*\*Кодовый замок\*\* (`type: "codelock"`) с интерактивной панелью ввода цифр `0–9`.

\* Переключатель «Режим игрока / Режим редактора» (или флаг `DEV\_MODE` для скрытия кнопки редактора перед публикацией).

\* Сохранение прогресса игрока в `localStorage` (с кнопкой «Начать игру заново»).
